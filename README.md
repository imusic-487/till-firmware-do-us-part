A [make.fun](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) bounty entry: one funny, heartfelt sentence a robot says at its own wedding.

`main.py` writes the vow to `/output/entry.txt` — a single sentence under 200 characters:

> I take you as my forever firmware update — no rollback, no factory reset — just you, my charger, my home, through every low battery and reboot, until my last battery dies.

Run it with:

```sh
python3 main.py
```

No dependencies, no network — just the Python standard library.
